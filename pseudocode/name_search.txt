Problem:
Search a list of names for one target name and report whether it was found.

Input:
- a list of names
- one target name

Output:
- "Found" or "Not found"
- or an error if the list is empty

Pseudocode:
START
IF the list is empty
    OUTPUT "Error: list is empty"
    END
END IF
SET found to false
FOR each name in the list
    IF name equals the target name
        SET found to true
    END IF
END FOR
IF found is true
    OUTPUT "Found"
ELSE
    OUTPUT "Not found"
END IF
END
