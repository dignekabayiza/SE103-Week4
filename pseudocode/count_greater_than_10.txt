Problem:
Count how many numbers in a list are greater than 10.

Input:
a list of numbers

Output:
the count, or an error if the list is empty

Pseudocode:
START
IF the list is empty
    OUTPUT "Error: list is empty"
    END
END IF
SET count to 0
FOR each number in the list
    IF number is greater than 10
        ADD 1 to count
    END IF
END FOR
OUTPUT count
END
