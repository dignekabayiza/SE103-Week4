What a pull request asks teammates to do:
A pull request asks teammates to review my changes before they are merged into main. They can read the code, leave comments, and approve or request fixes.

Why branches and pull requests are used together:
A branch keeps my work separate from main, and a pull request is the way to propose merging that work. Together they let a team check changes first, so main stays stable.

One thing that confused me in this project and how I solved it:
